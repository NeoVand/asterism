# Explaining concepts

1. `search_graph` with `types: ["term"]` to find the glossary concept (acronyms expand
   automatically). `explore` it: its definition, related concepts and every chapter that uses it.
2. Explain in three beats, citing facts:
   - **In one sentence** — the shortest correct definition.
   - **How it works / an example from a mine, quarry or construction site** — use the glossary's
     facts, not invented analogies.
   - **Why it matters here** — what the booklet concluded about it for validating automatic braking
     on heavy machines before mid-2027.
3. Offer 2–3 related concepts as next steps (with their t-ids so they light up).
Keep it short unless the user asks for depth.
